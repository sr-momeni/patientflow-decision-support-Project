# Legacy Module (CTAS 1-3)

This directory contains an older or simplified version of the patient flow logic that supports **CTAS Levels 1-3 only**.

## Contents
- **backend/**: Contains the Python source code for the legacy agents and simulation.
- **frontend/**: (Empty) This version does not include a frontend.

## Usage
This code is preserved for reference and backwards compatibility. It is **not** active in the main application (which uses CTAS 1-5).

To run or inspect this version, navigate to this directory. Note that you may need to adjust python paths or move `main.py` to the root to run it effectively, as it was originally designed as a standalone project root.
